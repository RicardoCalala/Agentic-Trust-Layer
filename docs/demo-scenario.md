# Demo Scenario: A Controlled Customer Message

1. A support agent retrieves approved internal guidance through an MCP tool. The policy allows this read-only action.
2. The agent drafts a reply that includes confidential account context.
3. The trust layer identifies the external message and requires approval.
4. A support lead reviews the draft and approves it.
5. The downstream messaging tool receives the approved request.
6. The audit log records the policy result, approval, reviewer, and integrity-protected event chain.

This short scenario demonstrates that agents can remain useful without receiving unrestricted authority.
