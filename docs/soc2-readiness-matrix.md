# SOC 2 Readiness Control Matrix

SOC 2 certification applies to an operating organization and is assessed independently. This matrix shows how the product can support readiness.

| Control area | Product capability | Evidence to retain |
| --- | --- | --- |
| Logical access | Default-deny policy, workload identity, scoped MCP access | Policy versions, access decisions, identity claims |
| Change management | Approval workflow for policy and high-impact actions | Request, reviewer, decision, timestamp |
| Monitoring | Audit-event export and integrity verification | Alerts, review records, incident tickets |
| Confidentiality | Data classification and destination-aware policy | Classification decisions, redaction events |
| Availability | Fail-closed design, health monitoring, recovery plan | Uptime reports, tests, recovery exercises |

## Operational requirements

Production readiness also requires control owners, access reviews, incident response, secure development practices, backups, vendor management, and periodic independent assessment.
