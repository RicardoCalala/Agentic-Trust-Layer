# Use Case: Governed Fraud Operations

A bank uses an AI agent to triage suspicious activity, combine approved signals, and prepare an investigator-ready case. The agent may read authorized case data and create a draft. It cannot freeze an account, file a report, disclose data, or release funds without policy authorization and a human reviewer.

The trust layer evaluates each MCP tool call, applies least privilege, preserves evidence references, and records an audit decision. This lets investigators focus on judgment while maintaining separation of duties and a clear explanation of how the agent was used.
